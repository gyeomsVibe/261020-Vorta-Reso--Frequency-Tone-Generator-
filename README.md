# 보르타 레조 (Vorta Reso) 주파수 발생기

노후 스마트폰을 **저주파 사인파(sine wave, 가장 순수한 한 가지 떨림) 전용 발생기**로 바꾸는 안드로이드 앱과 설정 도구입니다. 폰이 소리 신호를 만들면, 3.5mm 케이블로 연결된 우퍼 앰프가 그 신호를 바닥·지지대의 진동으로 바꿉니다.

> 처음이라면 1~3장만 읽어도 시연할 수 있습니다.

---

## 1. 한눈에 보기

```
[스마트폰 앱] --3.5mm AUX 케이블--> [우퍼 앰프] --> [우퍼/진동판] --> 바닥·지지대 진동
     ↑ C타입: 24시간 충전 전용 (오디오와 분리)
```

| 폰 | 앱 폴더 | 앰프 | 노브 조절 |
|---|---|---|---|
| Galaxy A30 | `smato_a30_app/` | 스마토 우퍼 #1 (120W 모노) | 볼륨 다이얼 1개, 11~1시 |
| Galaxy S7 | `vorta_s7_app/` | 스마토 우퍼 #2 (240W 스테레오, 우퍼 2개) | 볼륨 다이얼 1개, 11~1시 |
| Galaxy S6 | `vorta_s6_app/` | 트랜스2 Lepy LP-168S | SUB VOL 3~5시, X-OVER 80 Hz, BASS 0 dB |

세 앱은 패키지 이름(package name, 앱 고유 주소)이 서로 달라서 **한 폰에 함께 설치**할 수 있습니다(시연용 Note 20에서 확인).

## 2. 설치 (APK 파일 넣기)

준비물은 PC, USB 케이블, 그리고 폰의 **USB 디버깅**(개발자 옵션 안의 스위치)입니다.

> APK 파일은 저장소에 들어 있지 않습니다. 각 앱 폴더의 빌드 스크립트(`build_s6.py`, `build_s7.py`, A30 빌드 스크립트)로 PC에서 만듭니다. Android SDK와 JDK가 필요합니다.

1. 폰: 설정 → 휴대전화 정보 → 소프트웨어 정보 → "빌드번호"를 7번 누르면 개발자 옵션이 켜집니다. 그 안에서 USB 디버깅을 켭니다.
2. PC에 연결하고, 폰 화면의 "USB 디버깅 허용"을 누릅니다.
3. 아래 중 하나를 고릅니다.
   - **전용 기기로 만들 때**: `A30_S7_S6_보르타_레조_환경설정_원클릭.bat`을 더블클릭합니다. 모델을 자동으로 알아내서 불필요한 앱을 정리하고, 24시간 설정을 적용한 뒤 맞는 앱을 설치합니다. 끝에 `[pm] done`이 보이면 정상입니다.
   - **시연만 할 때(폰 설정 변경 없음)**: 앱만 설치합니다.
     ```
     adb install -r -d smato_a30_app/smato_a30_pro.apk
     ```
     폰이 여러 대 연결되어 있으면 `adb -s <시리얼> install ...`처럼 시리얼을 지정합니다.

## 3. 사용 (시연 순서)

1. 앰프 전원을 켭니다(빨간 램프).
2. 폰의 3.5mm 잭을 **"딸깍" 소리가 날 때까지** 끝까지 꽂습니다. 케이스가 막으면 벗기세요.
3. 앱에서 시나리오를 고르고 재생합니다. 화면의 신호등이 초록으로 바뀌고, 앰프 노브의 **파란 램프**(신호 표시)가 켜집니다.
4. 앰프 노브를 1장 표의 범위까지 천천히 올립니다.

## 4. 소리가 안 날 때

| 증상 | 원인 | 해결 |
|---|---|---|
| 앱은 재생 중인데 파란 램프가 꺼져 있음 | 폰이 잭을 인식하지 못해 소리가 폰 스피커로 나감 | 잭을 뺐다가 끝까지 다시 꽂기 |
| 빨간 램프도 꺼져 있음 | 앰프 전원 문제 | 어댑터와 스위치 확인 |
| "퍽·지직" 소리 | 앰프 노브를 과하게 올려 파형 꼭대기가 잘림(클리핑, clipping) | 노브를 표의 범위로 낮추기 |
| bat이 멈춤 | (이전 버전) 앱 삭제 명령이 응답하지 않음 | 최신 bat 사용. 8초 후 강제 종료됨 |

## 5. 안전 장치 (자동으로 동작)

- **우퍼 보호**: 재생 시작 때 1초에 걸쳐 서서히 커지고(fade-in), 정지할 때 0.5초에 걸쳐 서서히 작아집니다(fade-out). 시나리오가 바뀔 때도 파형이 끊기지 않습니다.
- **출력 상한**: 디지털 최대보다 1 dB 낮은 −1.0 dBTP(Peak 29200)를 넘지 않습니다.
- **배터리 보호**(전용 기기 설정 시): 85%까지만 충전하고 급속충전을 끕니다. 배터리가 부풀어 오르는 현상(스웰링, swelling)을 줄이기 위한 설정입니다.
- **시나리오 우선**: 보호 장치는 시나리오의 주파수와 효과 값을 바꾸지 않습니다.
