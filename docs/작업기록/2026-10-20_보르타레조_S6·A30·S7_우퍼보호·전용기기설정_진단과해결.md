# 보르타 레조 S6·A30·S7 우퍼 보호와 전용기기 설정: 진단과 해결 기록 (2026-10-20)

> 대상: 처음 보는 사람. 전문용어는 처음 나올 때 괄호에 영어를 함께 적었다.
> 한 줄 요약: 우퍼가 "퍽·지직" 하던 원인은 소리가 **갑자기 켜지고 꺼지는 순간의 충격**이었다. 소리를 1초에 걸쳐 서서히 키우고 0.5초에 걸쳐 서서히 줄이도록 고쳤다. 시나리오의 주파수와 효과 값은 하나도 바꾸지 않았다.

---

## 1. 무엇이 문제였나 (증상)

| 번호 | 증상 | 기기 |
|---|---|---|
| P1 | 우퍼에서 굉음이 나고, 불안한 잡음(노이즈, noise)이 섞임 | A30·S7·S6 모두 |
| P2 | 트랜스2는 노브를 3~6시까지 돌려야 진동이 느껴짐 | S6 + Lepy 앰프 |
| P3 | 24시간 켜 두면 배터리가 부풀(스웰링, swelling) 위험 | 노후 폰 3대 |
| P4 | 원클릭 설정 파일(bat)이 중간에 멈춤 | 설정 PC |
| P5 | S6 상태 화면에 신호등 램프와 현재 시나리오가 안 보임 | S6 |

## 2. 원인 진단 (왜 그랬나)

비유로 먼저 보자. 스피커 콘(cone, 진동판)은 **그네**와 같다. 그네를 천천히 밀면 높이 올라가지만, 멈춰 있는 그네를 갑자기 세게 걷어차면 줄이 덜컹한다.

| 원인 | 쉬운 설명 | 정확한 사실 |
|---|---|---|
| C1 급시작·급정지 | 소리를 0에서 바로 최대로 켜고 끔 → "퍽" | 이전 코드는 재생 시작 때 이득(gain, 증폭 비율)이 바로 1이었고, 정지 때 바로 잘렸다 |
| C2 위상 리셋 | 시나리오가 바뀔 때 파도의 "위치"를 0으로 되돌림 → 파형이 뚝 끊김 | `mPhaseResetRequested`가 위상(phase)을 0으로 초기화했다 |
| C3 앰프 과진폭 | 앰프 노브를 너무 올리면 파형 꼭대기가 잘림(클리핑, clipping) → 찌그러진 소리 | 앱 출력 최대치는 Peak 29200 = −1.0 dBTP(디지털 최대보다 1 dB 낮은 안전선)로 이미 제한돼 있었다 |
| C4 bat 멈춤 | 앱 삭제 명령(pm)이 응답 없으면 영원히 기다림 | `timeout 8`은 "멈춰 달라"는 신호(TERM)만 보낸다. 무시하는 pm은 끝나지 않는다 |
| C5 배터리 | 100% 충전 상태로 24시간 유지 → 화학적 스트레스 | 삼성 `protect_battery`(85% 충전 제한)가 꺼져 있었다 |

## 3. 어떻게 고쳤나 (해결)

### 3-1. 우퍼 보호 엔진 (C1·C2 해결) — 세 앱 공통

- **페이드인(fade-in)**: 재생을 시작하면 1초에 걸쳐 소리를 0 → 최대로 올린다.
- **페이드아웃(fade-out)**: 정지하면 0.5초에 걸쳐 줄인 뒤 끈다(최대 0.8초 기다림).
- **위상 연속**: 시나리오가 바뀌어도 파형을 끊지 않고 이어 간다.
- **주파수 하한 1 Hz**: 엔진이 0 Hz(직류, DC)를 내보내 콘을 한쪽으로 밀어 두는 사고만 막는다.

**예시 (FEW-SHOT: 같은 구조, 다른 값)**

| 입력 | 이전 동작 | 지금 동작 |
|---|---|---|
| A30, 17.3 Hz 시작 | 첫 순간부터 Peak 29200 → "퍽" | 첫 버퍼 Peak 1840 → 1초 뒤 29200 |
| S7, 17.3 Hz 시작 | 같은 충격 | 첫 버퍼 Peak 2128 → 서서히 상승, 17.30 Hz 정확 |
| S6, 시나리오 전환 | 위상 0으로 점프 → "틱" | 파형이 이어져 무음 전환 |

### 3-2. 바꾸지 않은 것 (원칙 16: 설정은 시나리오의 하인)

처음에는 20 Hz 미만을 막고 효과(RM·부스트)를 끄는 안을 넣었다. 그러면 A30의 17.3~19.8 Hz 시나리오와 S6의 RM 20% 시나리오가 깨졌다. 그래서 **되돌렸다**. 환경설정과 보호 장치는 시나리오를 더 잘 돌리기 위해서만 존재하고, 시나리오를 바꾸면 안 된다.

### 3-3. 앰프 노브 안내 (C3 해결) — 기기별로 다름 (원칙 7·15)

| 기기 | 앰프 | 조절 방법 |
|---|---|---|
| A30 | 스마토 우퍼 #1 (120W 모노) | 볼륨 다이얼 하나뿐, 11~1시 |
| S7 | 스마토 우퍼 #2 (240W 스테레오, 우퍼 2개) | 볼륨 다이얼 하나뿐, 11~1시 |
| S6 | 트랜스2 Lepy LP-168S | SUB VOL 3~5시, X-OVER 80 Hz, BASS 0 dB |

X-OVER·SUB 노브는 **S6의 Lepy에만** 있다.

### 3-4. 배터리 보호 (C5 해결)

| 설정 | 값 | 뜻 |
|---|---|---|
| `protect_battery` | 1 | 85%까지만 충전 |
| `adaptive_fast_charging` | 0 | 급속충전 끔 → 발열 감소 |
| `stay_on_while_plugged_in` | 0 | 충전 중에도 화면이 꺼짐 |

측정 결과 S6 28.1 °C, A30 24.6 °C였다.

### 3-5. 안전볼륨 (기기별 예외)

- S7·S6: `audio_safe_volume_state=2`로 "음량이 너무 큽니다" 경고창만 끈다. 볼륨 값은 고정하지 않는다(원칙 1).
- **A30: 적용하지 않는다.** A30은 원래 제한이 없으므로 설정을 넣으면 불필요한 간섭이 된다. 잘못 넣었던 값은 삭제했다(원칙 1 예외 기록).

### 3-6. bat 멈춤 (C4 해결)

- `timeout -k 2 8`: 8초 뒤 "멈춰라"를 보내고, 2초 더 버티면 강제 종료(KILL)한다.
- 설치되지 않은 앱은 pm을 부르지 않고 건너뛴다.
- 끝나면 `[pm] done`을 출력한다. 이 줄이 보이면 정상이다.
- 삭제 목록에 갤럭시 스토어(`com.sec.android.app.samsungapps`)를 추가했다.

### 3-7. S6 화면 (P5 해결)

상태 카드에 신호등 램프를 넣었다(대기 빨강, 재생 초록). 현재 시나리오 줄도 추가했다(재생 중 하늘색).

## 4. 실제로 겪은 함정 (다시 하지 말 것)

| 함정 | 증상 | 교훈 |
|---|---|---|
| 잭 미인식 | 앱은 정상 출력인데 앰프의 파란 신호 램프가 꺼짐 | 출력 장치가 SPEAKER뿐이면 3.5mm 잭이 덜 꽂힌 것이다. 끝까지 "딸깍" 꽂는다 |
| 여러 폰 연결 | `adb: more than one device` | 항상 `adb -s <시리얼>`을 쓴다 |
| 감사 로그 DC 값 | DC가 0이 아니게 보임 | 20 ms 측정창이 한 주기보다 짧아서 생긴 착시다. 실제 직류가 아니다 |

## 5. 검증 결과 (확인된 사실 / 미확인)

- 확인: 세 앱 빌드·설치 성공, 주파수 정확(17.30 Hz, 7.83 Hz), Peak 상한 29200, 페이드인 동작, 배터리 설정값.
- 사용자 확인: A30·S6 실제 작동 OK.
- 미확인: S7 앰프 연결 상태의 청음, bat 수정판의 실기 실행, Note 20 시연용 설치(기기 미인식).
